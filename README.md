# Projeto QA – Testes de Login

## Sobre o projeto
Este é um projeto prático na área de Quality Assurance (QA), desenvolvido para praticar testes funcionais de um sistema de login utilizando Python.

## Objetivo
Verificar se o sistema de login apresenta os resultados esperados em diferentes situações.

## Tecnologias e ferramentas
- Python
- OnlineGDB
- GitHub

## Casos de teste

| ID | Cenário | Resultado |

| CT001 | Login correto | Aprovado |
| CT002 | E-mail incorreto | Aprovado |
| CT003 | E-mail e senha vazios | Aprovado |
| CT004 | E-mail vazio | Aprovado |
| CT005 | Senha vazia | Aprovado |
| CT006 | Senha com espaços extras | Aprovado |

## Resultado final
6 casos de teste executados e 6 aprovados.

## Conhecimentos praticados
- Testes funcionais
- Criação de casos de teste
- Identificação de comportamentos incorretos
- Registro de resultados
- Lógica condicional em Python
